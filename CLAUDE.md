# ChatBox View

Android AI chat application supporting multiple models, character personas, and local-first data storage.

## Tech Stack

- **Language**: Kotlin (AGP 9.2.1 built-in Kotlin support)
- **UI**: XML Layouts + Material Design 3 (no Jetpack Compose)
- **Min SDK**: 30 / **Target SDK**: 36
- **Java**: 17
- **Package**: `com.gao.chatbox.view`
- **Module**: Single `:app` module

### Current Dependencies

- AndroidX Core KTX 1.18.0
- AppCompat 1.7.1
- Material 1.12.0
- ConstraintLayout 2.2.1
- Lifecycle Runtime KTX 2.10.0

### Dependencies To Add

- **Room** - Local database (messages, conversations, models, settings)
- **Hilt** - Dependency injection
- **Navigation Component** - Fragment-based navigation
- **ViewModel + LiveData/Flow** - Reactive state management
- **Retrofit + OkHttp** - AI model API calls
- **DataStore** - Settings/preferences storage
- **Coroutines** - Async operations
- **Gson/Moshi** - JSON serialization

## Feature Requirements

### Home Screen (3 Tabs)

1. **Quick Entry** - New conversation, character list, create new character (system prompt editor)
2. **History** - Conversation list with search/filter
3. **Settings** - Model config, UI preferences, capabilities (web search)

### Chat Screen

- Editable chat title (auto-generated by AI)
- Message content display with statistics
- Context compression/summarization
- Copy/paste support
- Multi-modal input (text + images)

### Settings

- **Models**: List / Add / Delete / Edit model configurations (API URL, key, model name)
- **UI**: Show message char count, token count, model name, timestamps
- **Capabilities**: Web search toggle

### Data Layer (Room Database)

**Tables needed:**
- `conversations` - id, title, character_id, model_id, created_at, updated_at
- `messages` - id, conversation_id, role, content, token_count, created_at
- `characters` - id, name, avatar, system_prompt, created_at
- `models` - id, name, api_url, api_key, model_name, is_default, created_at

**Local storage:**
- Model configurations (Room)
- Settings/preferences (DataStore)
- All message content (Room)

### Conversation Implementation

- Send messages to AI API and stream responses
- Context window management with compression
- Multi-turn conversation history
- Token counting per message

## Code Style

- Use ViewBinding for layout references (not `findViewById`)
- Use Kotlin coroutines for async work
- Follow MVVM pattern: View -> ViewModel -> Repository -> DataSource
- Room entities use `@Entity`, DAOs return `Flow<List<T>>` for reactive queries
- Use sealed classes for UI state
- Use Material 3 components and theming (already configured in `colors.xml` / `themes.xml`)
